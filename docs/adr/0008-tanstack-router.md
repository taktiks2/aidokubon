# ルーターに TanStack Router を使う

「コンパイラをハーネスにする」方針を、フロントエンドのルーティングにも広げたい。TanStack Router なら、ルートのパス、パラメータ、URL のクエリまで型がつく。存在しないルートへのリンクや、パラメータの受け渡しの間違いは、型チェックで止められる。蔵書の検索画面の絞り込みの条件（`?q=...&status=...&group=...`）も、検証済みの型のついた値として扱える。

## Considered Options

| 案 | 見送った理由 |
|---|---|
| React Router v7（データモード） | パラメータに型がつかず、URL のクエリも自分でパースする必要がある。v5、v6、v7 で書き方が大きく違い、AI の出力が古い書き方に引っ張られやすい |
| React Router v7（フレームワークモード） | 本来はサーバーありが前提で、SPA だけの構成と合わない |
| wouter | 軽いが、型もデータの読み込みの仕組みもない |
