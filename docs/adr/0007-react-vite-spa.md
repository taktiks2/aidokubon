# フロントエンドを React + Vite の SPA にし、SSR のフレームワークは使わない

API とビジネスロジックはすべて Rust が持ち、ログインしてから使うアプリなので検索エンジン向けの最適化も要らない。フロントエンドのフレームワークのサーバー側の機能（SSR、Server Actions、API ルート）は出番がないため、画面だけを担当する SPA にし、静的ファイルとして配信する。PWA にして、スマホのホーム画面から開けるようにする。

## Considered Options

| 案 | 見送った理由 |
|---|---|
| Next.js | Node のサーバーがもう 1 つ増える。静的出力にすると機能の多くを捨てることになる。Pages Router と App Router の違いで AI の出力が混乱しやすい |
| SvelteKit | SPA モードにはできるが、Svelte 5 の runes の前後で書き方が変わり、AI の出力に古い書き方が混ざりやすい |
| Vue + Vite / Nuxt | 技術的には問題ないが、React ほど学習データと型まわりのエコシステムが厚くない |

## Consequences

- 一般公開したあとにランディングページなどの公開用のページが必要になったら、別に作る。
