# 退会したら本人のデータは完全に削除し、ほかの人のデータからの参照だけを空にして残す

一般公開を見越して、退会したらユーザーの行、読書ログ、蔵書などを物理的に削除する。ただし、ほかのユーザーのデータの中にある参照は、名前のない形で残す。対象は、退会した人が**借り手**だった**貸出**と、退会した人が入力した**個人の版**で、どちらも参照を NULL にする。貸出中の蔵書を持っている間と、グループの最後の管理者である間は退会できない。

## Considered Options

| 案 | 見送った理由 |
|---|---|
| すべてを完全に削除する（CASCADE で統一） | 退会しない人のデータが壊れる。母の蔵書が「誰にも貸していない」ように見えてしまい、本の現物の場所の記録が失われる。また、父の個人の版を使って登録した母の蔵書は、存在しない版を指すことになる |
| ユーザーの行を匿名化して残す（論理削除） | 「完全に消える」と説明できない。削除すべき個人情報の列が増えるたびに、匿名化の処理を保守し続ける必要がある |

## Consequences

- 外部キーごとに `CASCADE`（本人の持ち物）、`SET NULL`（ほかの人のデータからの参照）、`RESTRICT`（貸出中の蔵書など、削除を拒むべきもの）を使い分ける。
- `loans.borrower_id` と `editions.created_by` は NULL を許す。NULL は「退会したユーザー」と表示する。
