# Web フレームワークに axum を使う

axum を選ぶ理由は 3 つある。extractor（`FromRequestParts`）で、「メンバーであることを確認済み」といった権限を型として表せる。tower のミドルウェアの資産をそのまま使える。AI の学習データが最も多い。

## Considered Options

| 案 | 見送った理由 |
|---|---|
| actix-web | 機能はほぼ同等だが、ミドルウェアが独自の仕組みで、エコシステムと情報量で axum に劣る。速度の差はこの規模では意味を持たない |
| Loco | Rails のような全部入りのフレームワークで、標準の ORM が SeaORM。sqlx と自前の SQL という方針とぶつかる |
| Rocket | リリースの間隔が長く、OpenAPI の生成への対応が弱い |
