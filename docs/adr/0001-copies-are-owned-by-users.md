# 蔵書の所有者は常にユーザーとし、グループは所有者にならない

家族向けのサービスだが、「家の本」をグループの持ち物として扱わない。**蔵書**の**所有者**は常に 1 人の**ユーザー**とし、**グループ**は**公開**先（見える範囲）にすぎないものとする。1 冊を複数のグループに公開でき、メンバーがグループを抜けても蔵書の持ち主がはっきりしたまま残る。一般公開したあとの退会処理も単純になる。持ち主があいまいな本は、登録したユーザーを所有者とする運用で割り切る。

## Considered Options

| 案 | 見送った理由 |
|---|---|
| 所有者は常にグループ | 家族には自然だが、同じ本を職場のグループにも見せられない。子どもが独立してグループを抜けたとき、自分で買った本の扱いが決まらない |
| 蔵書ごとに、ユーザーの持ち物かグループの持ち物かを選ぶ | 所有者を示す列が 2 種類になり、貸出と権限の判定がどれも二股になる |

## Consequences

- どのグループに公開するかを蔵書ごとに管理する必要がある。手間を減らすために**自動公開**の設定を設ける（グループごとにメンバーが持ち、参加した時点ではオン）。
- 借り手の条件は「貸出を始めた時点で、その蔵書が公開されているグループのメンバーであること」とする。公開をやめたりグループを抜けたりしても、貸出は返されるまで続く。
