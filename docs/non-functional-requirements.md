# 非機能要件

2026-09-27 のセッションで決まった非機能要件をまとめる。理由と比較した候補は、各項目の ADR にある。用語は `CONTEXT.md` を参照する。

## 前提となる規模と段階

- 最初は学習・ポートフォリオと、自分の家族（数人）での利用。将来は一般公開する
- 家族の規模では、どのサービスも無料枠に収まることを前提とする

## 費用

| 要件 | 根拠 |
|---|---|
| 家族の規模では、月額をほぼ 0 円にする（ドメイン代は除く） | ADR-0011 |
| Secret Manager などの従量課金は、無料枠の範囲で使う | ADR-0011, ADR-0012 |
| 収益化はしない | 決定事項メモ |

## 性能

| 要件 | 根拠 |
|---|---|
| API と DB は同じリージョン（シンガポール）に置く。1 回の API の呼び出しで SQL を複数回投げるため | ADR-0011 |
| Cloud Run は、リクエストがないときにインスタンスを 0 台にする。使われていない状態からの起動の遅れは、Rust の起動の速さで抑える | ADR-0011 |
| 楽天ブックス API の結果は自前の DB にキャッシュし、レート制限に当たらないようにする | 決定事項メモ |

具体的な応答時間の目標値は、まだ決めていない。

## セキュリティ

| 要件 | 根拠 |
|---|---|
| 楽天 API のアクセスキーはサーバー側にだけ置き、ブラウザからは呼ばない | 決定事項メモ |
| パスワードは持たない。認証は OIDC のソーシャルログインだけにする | ADR-0010 |
| セッションは HttpOnly の Cookie と PostgreSQL に保存し、ログアウトやメンバーを外したときにその場で無効にできるようにする | ADR-0010 |
| SPA と API を同じオリジンに置き、CORS を開けない | ADR-0011 |
| 秘密の値は Secret Manager に置き、IaC の state ファイルに平文で残さない | ADR-0012 |
| CI から GCP へは、鍵を使わずに Workload Identity Federation で認証する | ADR-0012 |
| 権限の確認（グループのメンバーかどうかなど）は、axum の extractor の型で強制する | ADR-0003, ADR-0006 |

## プライバシーとデータの保持

| 要件 | 根拠 |
|---|---|
| **非公開の蔵書**、**読書ログ**、**読書メモ**、**進捗記録**は、本人だけが見られる | `CONTEXT.md` |
| **退会**したら、本人の情報と持ち物は完全に削除する。ほかの人のデータからの参照だけを、名前のない形で残す | ADR-0002 |
| 新しく参加したグループへは、既定で**自動公開**がオンになる。グループごとにオフにできる | ADR-0001 |

## 保守性

| 要件 | 根拠 |
|---|---|
| DB → Rust → OpenAPI → TypeScript の型の連鎖を切らない。生成した OpenAPI の仕様との差分と、TypeScript の型チェックを CI で検査する | ADR-0009 |
| SQL はコンパイル時に検査する。動的なクエリも、検査が効く範囲で書く | ADR-0005 |
| ドメインの規則は、できるだけ DB の制約として表現する | ADR-0004 |
| インフラはすべて IaC で管理する | ADR-0012 |

## 移植性と拡張性

| 要件 | 根拠 |
|---|---|
| API はステートレスなコンテナにする | ADR-0013 |
| 標準の PostgreSQL の機能だけを使う | ADR-0013 |
| 認証のセッションは、Cookie と `Authorization: Bearer` の両方で受け取れるようにする（将来のスマホのアプリのため） | ADR-0013 |

## 利用環境

| 要件 | 根拠 |
|---|---|
| スマホのブラウザで使える PWA にする。家族は LINE で届いたリンクから開く | ADR-0007 |
| バーコードの読み取りは iOS Safari でも動かす。そのため、ブラウザ標準の `BarcodeDetector` ではなく zxing-js を使う | 決定事項メモ |

## 法令と規約

| 要件 | 根拠 |
|---|---|
| 楽天 API の規約で決められたクレジットの表示を、MVP から入れる | 決定事項メモ |
